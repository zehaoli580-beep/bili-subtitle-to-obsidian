# BiliSubtitleToObsidian v1.0.0

首个可用版本：提取 B 站视频字幕，导出为 Obsidian 可直接识别的 Markdown 笔记。

## 下载

| 文件 | 说明 |
|---|---|
| `BiliSubtitleToObsidian-v1.0.0-win-x64.zip` | Windows 10 / 11 x64，免安装 |

解压后双击 `BiliSubtitleToObsidian.exe` 即可运行，无需安装 Node.js。

SHA256：`7C6124AACE8D9C05CC5EDA9E6B0898AF68542B8FABF26EB256389A0B1FD7EE5D`

> 应用未做代码签名，首次运行 Windows 可能提示 SmartScreen，选择「更多信息 → 仍要运行」即可。

## 功能

- 支持 BV 号、av 号、完整链接、`b23.tv` 短链，自动识别 `?p=` 分P参数
- 左侧展示封面、标题、UP主、简介与分P列表，可任选分P导出
- 扫码登录（B 站手机客户端）或手动粘贴 Cookie，登录态本地保存
- AI 字幕 / CC 字幕自动获取，多语言可切换
- 字幕自动校验 + 最多 8 轮重试，规避 B 站接口偶发返回错误字幕的问题
- 导出格式：时间戳逐句（可点击跳转）或纯文本段落，可选 YAML frontmatter
- 文件名自动清洗，重名自动追加序号
- 记住上次的导出目录与格式

## 使用方法

1. 粘贴视频链接，点「解析」
2. 右上角「扫码登录」，用 B 站手机客户端确认
3. 左侧选择要导出的分P
4. 选择 Obsidian 仓库内的保存目录
5. 点「导出」，完成后可点「打开目录」

## 已知问题

B 站 AI 字幕接口目前存在线上问题：同一个视频连续请求可能返回空数据或其他视频的字幕。程序已自动重试 8 轮并做三重校验，若标题栏出现橙色提示，点「重新获取」即可。

## 系统要求

- Windows 10 / 11（x64）
- 需要联网，并拥有可登录的 B 站账号
